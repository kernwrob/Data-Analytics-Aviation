# Source conditions and restricted project data

Checked 1 October 2026. This project is non-profit university research/education, with one collection computer. Code and data have different sharing conditions. Creating a local export does not upload or publish it.

## OpenSky position reports

[General terms](https://opensky-network.org/about/terms-of-use) limit use to non-profit research/education and restrict redistribution. Conditions must accompany subsequent permitted uses. They require attribution for publications, de-identification for disclosure, and eventual deletion subject to a reasonable reproducibility retention period. Operational applications and commercial use require separate written permission.

The [FAQ on colleague sharing](https://opensky-network.org/about/faq) supports same-organization colleagues assisting with the same approved project. The terms use narrower institute-employment wording. Do not assume a private GitHub repository or university login alone authorizes redistribution: confirm your student-group/course access with the lecturer or OpenSky if applicability is unclear. Separate-institution collaborators need their own access. No public raw-data links; do not post aircraft identifiers or raw trajectories in the public repository. Confirm Moodle handling with the lecturer.

Use a restricted university OneDrive/Teams folder with only the three project members and authorized course staff, after confirming the applicable access conditions. Include this document and the terms links with every dated package. Decide a retention/deletion date when the assessment/reproducibility period ends.

## Aircraft metadata

The official [aircraft database page](https://opensky-network.org/data/aircraft) says the reference is out of date, supplied without guarantees, unlicensed, and outside its general terms. This is not a public-domain or CC0 grant. Keep the original metadata within restricted project work; obtain clarification before redistributing it publicly. It mixes official registries and crowdsourced sources. The CSV downloaded in this project has a server Last-Modified timestamp of 4 November 2024; the dated local filename records retrieval, not freshness of every aircraft record.

The original CSV includes owner/registration fields. The prepared metadata table intentionally retains only identifier, manufacturer, model, type and description/category fields, plus the selection audit. Those identifiers still need appropriate handling for external disclosures.

## OurAirports

[OurAirports downloads](https://ourairports.com/data/) are released to the public domain without an accuracy guarantee. Credit the source in the presentation even though attribution is not required by that release.
